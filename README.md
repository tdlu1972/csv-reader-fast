A faster drop-in for csv-reader 1.0.0 that returns byte-identical `{columns, rows, errors}` answers, broken rows and all: one left-to-right pass over char codes that cuts each field out of the text with a single `slice()` instead of building it a character at a time. `main.ts` is the house driver (make.fun's csv-reader entry, MIT) unchanged.

## Run it

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
